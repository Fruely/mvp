# Froyle MVP - Платформа бронирования услуг

Полнофункциональный проект Next.js + TailwindCSS для платформы бронирования услуг здоровья и благополучия.

## 🚀 Возможности

- ✅ Responsive дизайн (desktop, tablet, mobile)
- ✅ Система бронирования с календарем
- ✅ Личный кабинет пользователя
- ✅ Админ-панель
- ✅ Mock API с имитацией задержки сети
- ✅ TailwindCSS для стилизации
- ✅ Font Inter
- ✅ Цветовая схема: Белый + Синий (#1E40AF)
- ✅ Hover эффекты (масштабирование, тени)

## 📁 Структура проекта

```
src/
├── components/
│   ├── Header.jsx          # Навигация и логотип
│   ├── Footer.jsx          # Подвал с контактами
│   ├── ServiceCard.jsx     # Карточка услуги
│   ├── Calendar.jsx        # Календарь бронирования
│   ├── BookingForm.jsx     # Форма записи
│   └── UserCard.jsx        # Профиль пользователя
├── pages/
│   ├── index.jsx           # Главная страница (услуги)
│   ├── booking.jsx         # Страница записи
│   ├── dashboard.jsx       # Личный кабинет
│   ├── admin.jsx           # Админ-панель
│   ├── _app.jsx            # App wrapper
│   └── _document.jsx       # HTML document
├── styles/
│   └── globals.css         # Глобальные стили TailwindCSS
├── utils/
│   └── api.js              # Mock API функции
└── assets/                 # Папка для изображений
```

## 🛠️ Установка и запуск

### Требования
- Node.js 16+
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Сервер запустится на `http://localhost:3000`

### Сборка для production
```bash
npm run build
npm start
```

### Lint проверка
```bash
npm run lint
```

## 📄 Страницы

### 1. Главная страница (`/`)
- Hero секция
- Список услуг в виде карточек
- CTA секция для контактов

### 2. Страница записи (`/booking`)
- Календарь выбора даты
- Форма заполнения данных
- Инструкция как это работает

### 3. Личный кабинет (`/dashboard`)
- Профиль пользователя
- Список активных записей
- Настройки уведомлений

### 4. Админ-панель (`/admin`)
- Статистика платформы
- Управление бронированиями

## 🎨 Компоненты

### Header
- Логотип с иконкой
- Навигация по страницам
- Выбор языка (РУ/EN/DE)
- Кнопка входа

### Footer
- Информация о компании
- Ссылки на услуги

- Политика конфиденциальности

### ServiceCard
- Изображение с эмодзи placeholder
- Название и описание услуги
- Цена и длительность
- Кнопка "Записаться"

### Calendar
- Навигация между месяцами
- Выбор даты
- Отображение выбранной даты

### BookingForm
- Поля: ФИО, Email, Телефон
- Выбор услуги
- Дата и время
- Дополнительные пожелания
- Валидация формы

### UserCard
- Аватар пользователя
- Контактная информация
- Статистика (количество записей, потрачено)
- Кнопки действий

## 📡 API Mock Functions

### fetchServices()
Получить все доступные услуги

### fetchServiceById(id)
Получить услугу по ID

### fetchUserProfile(userId)
Получить профиль пользователя

### fetchUserBookings(userId)
Получить все бронирования пользователя

### createBooking(bookingData)
Создать новое бронирование

### updateBooking(bookingId, updateData)
Обновить существующее бронирование

### cancelBooking(bookingId)
Отменить бронирование

### fetchAvailableSlots(serviceId, date)
Получить доступные слоты времени

### fetchAdminStats()
Получить статистику для администратора

## 🎯 Стили и тема

### Цвета
- **Primary**: #1E40AF (синий)
- **Secondary**: #ffffff (белый)
- **Gray**: оттенки серого для текста

### Компоненты CSS
- `.btn-primary` - основная кнопка
- `.btn-secondary` - вторичная кнопка
- `.card` - карточка с тенью
- `.container-custom` - контейнер с max-width
- `.section-title` - заголовок секции

### Hover эффекты
- Масштабирование (scale-105)
- Тень (shadow-lg)
- Плавные переходы (transition)

## 📝 Placeholder контент

Все текстовые данные и изображения являются placeholder'ами и могут быть заменены на реальные данные:

- Текст описаний услуг
- Изображения (используются эмодзи)
- Контактная информация
- Данные пользователя
- Цены и длительность услуг
