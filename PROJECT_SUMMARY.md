## 📡 API Mock Functions

Все функции находятся в `/src/utils/api.js`:

```javascript
// Услуги
✅ fetchServices()              // Получить все услуги
✅ fetchServiceById(id)         // Получить по ID

// Пользователи
✅ fetchUserProfile(userId)     // Профиль пользователя

// Бронирования
✅ fetchUserBookings(userId)    // Список бронирований
✅ createBooking(data)          // Создать бронирование
✅ updateBooking(id, data)      // Обновить бронирование
✅ cancelBooking(id)            // Отменить бронирование

// Слоты времени
✅ fetchAvailableSlots(serviceId, date)  // Свободные времени

// Администрирование
✅ fetchAdminStats()            // Статистика платформы
```

## 🎨 Стили и тема

### Цветовая схема
- **Primary**: #1E40AF (синий)
- **Secondary**: #ffffff (белый)
- **Gray**: оттенки серого

### Шрифт
- **Inter** (загружается из Google Fonts)

### Компоненты CSS
- `.btn-primary` - основная кнопка
- `.btn-secondary` - вторичная кнопка
- `.card` - карточка с тенью
- `.container-custom` - контейнер
- `.section-title` - заголовок секции

### Эффекты
- Hover масштабирование (scale-105)
- Тени (shadow-md, shadow-lg, shadow-xl)
- Плавные переходы (transition)

### Адаптивность
- Mobile-first подход
- Breakpoints: sm, md, lg, xl, 2xl
- Grid система TailwindCSS
