## 🎯 ПО ЗАДАЧАМ

### Я хочу запустить проект
1. Прочитайте [README.md](./README.md)
2. Следуйте [GETTING_STARTED.md](./GETTING_STARTED.md)
3. Запустите `npm install && npm run dev`

### Я хочу создать новый компонент
1. Читайте [COMPONENTS.md](./COMPONENTS.md)
2. Посмотрите примеры в [EXAMPLES.md](./EXAMPLES.md)
3. Используйте стили из [STYLES.md](./STYLES.md)
4. Если нужна помощь - [FAQ.md](./FAQ.md)

### Я хочу интегрировать API
1. Читайте [API.md](./API.md)
2. Посмотрите примеры в [EXAMPLES.md](./EXAMPLES.md)
3. Модифицируйте `src/utils/api.js`
4. Если ошибка - [FAQ.md](./FAQ.md)

### Я хочу добавить стили
1. Читайте [STYLES.md](./STYLES.md)
2. Проверьте примеры в [COMPONENTS.md](./COMPONENTS.md)
3. Модифицируйте `src/styles/globals.css`
4. Или добавьте inline классы TailwindCSS

### Я хочу развернуть на production
1. Прочитайте [DEPLOYMENT.md](./DEPLOYMENT.md)
2. Следуйте инструкциям для вашей платформы
3. Если ошибка - [FAQ.md](./FAQ.md)

### Я не знаю с чего начать
1. Прочитайте [PROJECT_SUMMARY.md](./PROJECT_SUMMARY.md)
2. Потом [GETTING_STARTED.md](./GETTING_STARTED.md)
3. Начните экспериментировать!
