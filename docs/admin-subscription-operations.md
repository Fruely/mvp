# Admin Commercial Access Operations Guide

Внутренний гайд команды Freuly по публикации профилей, разовому доступу к заявкам и тарифам специалистов.

## 1. Текущая продуктовая модель

Для новых специалистов действует схема:

`регистрация → невидимый draft → готовность профиля → бесплатная публикация базового профиля → клиентские заявки → разовый доступ к конкретной заявке ИЛИ Professional / Growth`.

Публикация базового профиля не требует оплаты тарифа. Платный продукт Freuly для специалиста — доступ к клиентскому спросу и дополнительные функции, а не сам факт присутствия в каталоге.

## 2. Канонические тарифы

- `starter` — технический / legacy-код. Не предлагать новым специалистам как публичный тариф.
- `basic` — **Freuly Professional**, 29 €/месяц.
- `premium` — **Freuly Growth**, 59 €/месяц.

Professional и Growth — необязательные варианты доступа к заявкам в рамках оплаченного периода. Без подписки специалист может покупать подходящие заявки отдельно, если для конкретного request offer доступен pay-per-lead checkout.

## 3. Публикация и видимость

- Полностью заполненный профиль может быть опубликован без Professional/Growth.
- Отсутствие платного тарифа само по себе не является причиной скрывать опубликованный профиль.
- Видимость может ограничиваться из-за неполного/недостоверного профиля, блокировки, нарушений правил, технического статуса или систематического отсутствия реакции на клиентские обращения — согласно действующей продуктовой политике.
- Legacy/transition статусы не являются новым бесплатным тарифом.

## 4. Клиентская заявка и контакт

Клиент может выбрать конкретного специалиста. В этом случае специалист получает первую возможность обработать обращение.

Контактные данные клиента не считаются бесплатной частью публичного профиля:
- активный Professional/Growth может давать entitlement к контакту в рамках тарифа;
- без тарифа конкретная заявка может быть куплена отдельно;
- до разблокировки показывается только безопасное превью.

Если специалист отказывается либо request offer истекает, заявка может быть перераспределена другому подходящему специалисту по правилам Lead Engine.

## 5. Source of truth

`specialist_plan` остаётся источником тарифного entitlement. Для разового доступа source of truth — соответствующий request offer + подтверждённый payment/access grant.

Публичную видимость нельзя выводить из наличия или отсутствия Professional/Growth. Контакт клиента нельзя открывать по client-side флагу, success URL или непроверенному платежу.

## 6. Ручные операции

Через админку можно проверять и при наличии основания корректировать тарифные статусы. Ручная смена статуса:
- не создаёт Stripe-платёж;
- не является подтверждением получения денег;
- не должна подменять pay-per-lead grant;
- допускается только по понятному операционному основанию.

## 7. Оплаченный Professional / Growth

### Professional

`plan_code = basic`, `plan_status = active`; период соответствует подтверждённой оплате.

### Growth

`plan_code = premium`, `plan_status = active`; период соответствует подтверждённой оплате.

Автоматического повторного списания нет. Следующий период приобретается новым ручным checkout.

Окончание тарифа прекращает тарифный entitlement к новым контактам, но само по себе не должно снимать бесплатную публикацию базового профиля.

## 8. Pay-per-lead

Разовая покупка заявки:
- относится только к конкретному request offer;
- не создаёт подписку;
- не должна автоматически менять публичную видимость профиля;
- становится entitlement только после серверного подтверждения платежа;
- refund/dispute обрабатывается по действующей политике access grant.

## 9. Партнёрская программа

Бесплатная регистрация и публикация профиля не являются партнёрской paid conversion.

Текущая квалифицирующая конверсия для партнёрской программы — первая успешная месячная оплата Professional или Growth привлечённым специалистом. Разовый pay-per-lead не создаёт партнёрскую комиссию.

## 10. Что нельзя делать

- Не говорить, что для публикации профиля обязательно нужно платить 29 €.
- Не скрывать профиль только потому, что у специалиста нет тарифа.
- Не обещать бесплатный доступ к контактам клиента вместе с бесплатным профилем.
- Не выдавать Professional/Growth вручную без фактического основания.
- Не считать разовую оплату заявки подпиской.
- Не обещать конкретное число заявок, клиентов, заказов или доход.

## 11. Операционный принцип

Freuly снижает входной барьер: **профиль можно опубликовать бесплатно**.

Freuly монетизирует **доступ к клиентскому спросу**:
- разовая покупка конкретной заявки;
- либо Professional/Growth с доступом к заявкам в рамках тарифа.
