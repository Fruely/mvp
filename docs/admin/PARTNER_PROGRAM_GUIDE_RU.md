# Инструкция по работе с партнёрской программой Freuly

Операционное руководство для сотрудников Freuly. Актуальная версия также доступна в админке: `/admin/help`.

## 1. Что такое партнёрская программа

Партнёр получает персональную реферальную ссылку вида `https://freuly.de/r/код-партнёра`.

Freuly автоматически учитывает переходы по этой ссылке и регистрации специалистов, которые пришли через неё.

Вознаграждение начисляется по правилам программы — только за **нового** специалиста с **первой успешной оплатой** подписки. Продления и повторные покупки не создают новое вознаграждение.

## 2. Как создать партнёра

1. Откройте раздел **Партнёры** в боковом меню (`/admin/partners`).
2. Заполните форму **Создание партнёра**:
   - **Имя партнёра**
   - **Email**
   - **Реферальный код** — уникальный короткий код; подставляется автоматически из email, можно изменить до создания
   - **Справочная ставка** — для внутренней справки; фактическое вознаграждение рассчитывает система
3. Нажмите **Создать активного партнёра**.
4. Скопируйте полную реферальную ссылку из таблицы.

## 3. Как получить реферальную ссылку

После создания партнёра полная ссылка отображается в таблице — например: `https://freuly.de/r/ivan-abc1`.

Используйте кнопки **Скопировать ссылку** или **Открыть ссылку**. Не нужно вручную дописывать домен.

**Не меняйте рабочий реферальный код**, если ссылка уже разослана партнёру.

## 4. Где использовать реферальную ссылку

- Telegram, Facebook, Instagram, WhatsApp
- Email-рассылки
- Сайт или блог партнёра
- QR-коды и офлайн-материалы

> Это ссылка **партнёрской программы**. Не путайте её с рекламными ссылками клиентов (`/go/...`) и ссылками «Принять заявку».

## 5. Как проверить работу ссылки

1. Откройте ссылку — должен открыться сайт Freuly.
2. Проверьте счётчик **Переходы** в таблице партнёров.
3. Не создавайте искусственные оплаты ради проверки.

## 6. Что означают показатели

| Показатель | Значение |
|---|---|
| **Переходы** | Зафиксированные переходы по реферальной ссылке |
| **Регистрации** | Специалисты, чья регистрация привязана к партнёру |
| **Начислено** | Сумма одобренных комиссий в EUR |

## 7. Статусы партнёра

| Статус | Смысл |
|---|---|
| **Активен** | Ссылка работает, новые переходы учитываются |
| **Приостановлен** | Новые переходы по ссылке не принимаются |
| **Отключён** | Партнёр не участвует в программе |

## 8. Как работать с выплатами

1. Партнёр запрашивает выплату — заявка появляется в **Выплаты партнёрам**.
2. Проверьте сумму и партнёра.
3. Выполните банковский перевод **вне Freuly**.
4. **Только после перевода** нажмите **Отметить выплаченным**.

> **Не отмечайте выплату выполненной до фактического банковского перевода.**

## 9. Возвраты / отмены платежей

Если платёж клиента возвращён, комиссия может быть отменена (reversed). Сумма перестаёт быть доступной для выплаты.

## 10. Частые ошибки

- Не создавайте новую запись, если партнёр уже существует
- Не меняйте вручную рабочую реферальную ссылку без необходимости
- Не отмечайте выплату выполненной заранее
- Не путайте реферальную ссылку с `/go/...` (рекламные ссылки клиентов)
- Не путайте её со ссылкой «Принять заявку» для специалистов
- Не используйте чужой referral code для другого партнёра

## 11. Три типа ссылок Freuly

| Тип | Пример | Назначение |
|---|---|---|
| **A. Реферальная ссылка партнёра** | `https://freuly.de/r/...` | Учёт партнёра: переходы и регистрации специалистов |
| **B. Рекламная ссылка для клиентов** | `https://freuly.de/go/...` | Реклама → форма заявки клиента |
| **C. Ссылка «Принять заявку»** | `https://freuly.de/{язык}/request/{токен}/accept` | Специалист принимает продвигаемую заявку |
